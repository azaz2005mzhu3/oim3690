# Week 2 Notes

## What I worked on
This week, I worked more with HTML and GitHub. I practiced reading an index.html file and tried to understand what the different parts of the code actually do instead of just copying the code. I also worked with hello.html and learned more about using GitHub and VS Code.

## What gave me trouble
Since I do not have much coding experience, reading AI-generated HTML was a little confusing at first. There were many tags and parts of the code that I did not recognize. I was also confused about the difference between commit, push, and pull in Git. I am starting to understand them, but I still need more practice using them without instructions.

Some questions I had while reading the AI-generated code were:
- What does `<meta charset="UTF-8">` do?
- What is the difference between `<ul>`, `<ol>`, and `<li>`?
- What does `alt` do inside an image tag?
- How does an image path work if the image is stored in a folder?
- What is the difference between commit, push, and pull?

## Something new I learned
One thing I learned this week is that pull brings changes from GitHub down to my local computer, while push sends my local commits to GitHub. I also learned that index.html is the page that loads when someone visits the main URL of a GitHub Pages site.

I also learned that HTML tags have different purposes. For example, `<ul>` creates an unordered list, `<ol>` creates an ordered list, and `<li>` represents an item inside a list.

## Working with AI
This week I realized that AI can generate a webpage very quickly, but that does not mean I understand the code it creates. I found it more useful to ask AI about specific lines or tags that I did not understand instead of just asking it to build the entire page for me. Reading the AI-generated code line by line helped me understand what it was actually changing. I still need practice reading code on my own, but I feel more comfortable with HTML and GitHub than I did last week.
