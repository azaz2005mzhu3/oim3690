# Week 3 Notes

## What I worked on
- This week I started Mini Project 1, where I am building a personal website for my sister.
- I started setting up the website and thinking about how I want the pages to look and feel.
- While building the site, I also got more practice using CSS for things like colors, spacing, fonts, and the overall layout.

## What gave me trouble, and where I am still stuck
- I am still getting used to understanding how different CSS rules affect different parts of the page.
- Sometimes I know how I want the website to look, but I am not sure what CSS I need to use to make it happen.
- I also want to get better at reading the CSS instead of depending on AI to make every change for me.

## Something new I picked up
- Working on Mini Project 1 helped me understand CSS better because I was actually using it on a real website instead of only looking at examples.
- I learned that small changes in spacing, fonts, colors, and layout can make a big difference in how professional a website feels.
- I also learned more about design direction and why it helps to decide on a consistent style before building the whole site.

## Something I noticed about working with AI this week
- I noticed that AI works better when I describe the design I want more specifically instead of just asking it to make the website look better.
- For my sister's website, I still have to make the main design decisions myself because AI does not automatically know the style or feeling I want.
- I am starting to use AI more as a tool to help me build and adjust the site, rather than just accepting whatever it generates first.
