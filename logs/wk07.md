### Something new I picked up

- console.log() displays a value in the Console, while return sends a value back to the code that called the function.
- An if / else if chain stops at the first true condition, so the order of the conditions matters.
- === checks both value and type. For example, 5 === "5" is false.
- textContent displays user input as text, while innerHTML interprets it as HTML.

The difference between console.log() and return is especially useful for understanding a calculator. A calculation needs to return a value so another part of the program can use it.
