# Week 10 Notes

## What I Learned

This week, we learned more about Browser APIs, browser extensions, and how to integrate AI models into websites using LLM APIs. I learned that JavaScript can do more than just make webpages interactive. It can also connect to browser features and external services to build more useful applications.

Some important concepts we covered include:

- **Browser APIs:** Features like localStorage, Clipboard API, and Geolocation API allow websites to interact with the browser and improve user experience.
- **Browser Extensions:** Use JavaScript and DOM manipulation to add new features to existing websites.
- **LLM APIs:** Allow developers to connect AI models to their own applications and generate responses based on user input.
- **API Keys and Security:** API keys should not be exposed in frontend code. We can use serverless functions and environment variables to protect them.
- **Tokens:** AI models process text in tokens, which affect both the amount of information they can handle and the cost of API requests.
- **System Instructions:** Help guide an AI model's behavior and customize it for specific tasks.
- **RAG:** Retrieval-Augmented Generation allows AI to use information from external sources to provide more relevant answers.
- **Conversation Memory:** Chatbots maintain context by including previous messages in API requests.
- **AI Agents:** Unlike basic chatbots, AI agents can use tools and functions to perform tasks.

## Key Takeaways

One thing I found interesting was how many useful features we can build using JavaScript and existing Browser APIs without needing a complicated backend. For example, localStorage can save user preferences, while the Clipboard API makes sharing information easier.

I also learned that AI models do not automatically remember conversations. Developers need to manage conversation history and send relevant context with each request. This helped me better understand how AI chatbots work behind the scenes.

Another important takeaway was API security. I now understand why we should use serverless functions to communicate with AI services instead of putting private API keys directly into frontend JavaScript.

## Reflection

Before this week, I mainly thought of JavaScript as a way to create interactive webpages, and I had used AI tools without really understanding how they were integrated into websites. Learning about Browser APIs and LLM APIs helped me see how these technologies work together.

I think these concepts could be useful for my Smart Travel Packing Planner project. For example, I could use localStorage to save a user's packing list and integrate an AI model to generate personalized packing suggestions based on their destination and travel plans.

Overall, this week helped me understand how to build more practical and intelligent web applications while considering security, usability, and API costs.
