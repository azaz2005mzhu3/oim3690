## Something new I picked up

The debugging exercise gave me concrete examples of several JavaScript ideas:

- An array must be declared outside the submit handler if it should keep earlier entries.
- A function needs to return its calculated total so another part of the code can use it.
- Deleting a visible element and deleting its stored data are separate actions.
- A loop can build a list, calculate a total, or find the largest value.

For my GPA calculator, I want to get better at identifying the data being stored and the calculation that uses it, so I can explain what would happen if a line changed.
