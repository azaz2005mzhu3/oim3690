Something new I picked up

This week, I learned several important JavaScript and API concepts:

fetch() sends a request to an API and returns a Promise.

async allows a function to use await.

The first await waits for the HTTP response.

The second await waits for the response body to be parsed into JSON.

A GET request retrieves data, while a POST request sends data.

JSON.stringify() converts a JavaScript object into a JSON string for a request body.

response.ok helps check whether an HTTP request succeeded.

try/catch allows the webpage to handle errors instead of failing without feedback.

CORS can prevent a webpage from reading data from an API, even when the API URL works elsewhere.

One important thing I learned is that a successful API response is only the first step. My website also needs to read the correct fields and turn the data into something useful for the user.

This connects directly to my Smart Travel Packing Planner because I need to use weather information to calculate packing recommendations rather than simply display the API response.

Something I noticed about working with AI this week

AI was helpful for building the message board interface and explaining how to use fetch(), await, and error handling. It made the coding process faster, especially when I was unsure how to connect a button to an API request.

However, I noticed that AI can finish writing code without actually testing it in a browser. For example, my message board code was updated, but the agent explained that it had not sent a test message.

This reminded me that I need to distinguish between code that has been written and code that has actually been tested.

I also learned that AI-generated design suggestions do not have to be my final choice. For Mini Project 3, I compared two designs and selected Warm Editorial instead of the original Sky Blue Minimalist direction. This showed me that I can use AI to explore ideas while still making my own decisions.
