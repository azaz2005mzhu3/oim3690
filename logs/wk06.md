## Predict Before You Delete

### 1. An `addEventListener` Line

Line from `js/todo.js` I deleted:

```js
form.addEventListener("submit", (event) => { ... });
```

**Prediction:**  
I thought that if I deleted this line, I would not be able to add a new task.

**What happened:**  
I could still type in the input box, but submitting the form did not add the task to the list.

**Was I right?**  
Yes. I learned that this event listener connects submitting the form to adding a new task.

### 2. A Line That Changes the Page

Line from `js/todo.js` I deleted:

```js
list.appendChild(item);
```

**Prediction:**  
I thought the tasks would stop appearing on the page.

**What happened:**  
The tasks did not show up in the list because this line is what actually adds each task element to the page.

**Was I right?**  
Yes.

### 3. A Line of My Choice: Saving the Tasks

Line from `js/todo.js` I deleted:

```js
localStorage.setItem(STORAGE_KEY, JSON.stringify(todos));
```

**Prediction:**  
I thought I could still use the to-do list, but my changes would disappear after refreshing the page.

**What happened:**  
I could still make changes on the page, but after refreshing, the new changes were not saved.

**Was I right?**  
Yes. I learned that `localStorage` is what lets the page remember the changes.
